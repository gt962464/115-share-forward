# CD2 挂载自动移动

监控 123 云盘挂载目录，把上传完成的文件移动到 115 云盘挂载目录。

- 源目录：`/vol2/1000/转存`
- 目标目录：`/vol2/1000/CloudDrive/自动转存`
- 每 30 秒扫描一次；文件连续两次大小和修改时间不变才处理
- 先写入目标目录的 `.cd2sync.*.part` 临时文件
- 目标文件大小校验通过后改名，再删除源文件
- 复制或校验失败时保留源文件并自动重试
- 含目录层级的剧集按顶层目录聚合，等待同批文件稳定后只写入一个 115 闭环任务
- 首次启动只登记已有文件，不移动部署前已经存在的文件

状态保存在 `state/state.json`，不要删除该文件，否则服务会重新建立基线。
