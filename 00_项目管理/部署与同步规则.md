# 部署与同步规则（强制）

> 本文件记录 115 分享转发项目的操作纪律，每次修改代码必须遵守。

## 三端同步规则

每次代码变更完成后，必须同步到三个位置，缺一不可：

| 位置 | 路径 | 说明 |
|------|------|------|
| NAS | `/vol2/1000/docker/115/card-bot/cardbot.py` | 实际运行环境，**含 .env** |
| Git | `gt962464/minis-projects` → `115分享转发/` | 版本备份 |
| 桌面 | `C:\Users\15102\Desktop\Workspace\Project-006-115分享转发\` | 本地工作区 |

## NAS .env 保护规则

- **绝不删除、覆盖或修改** NAS 上的 `/vol2/1000/docker/115/card-bot/.env`，除非用户明确指示。
- 同步代码时只替换 `.py`、`.yml`、`Dockerfile` 等源码/配置文件。
- `.env` 仅通过管理后台（`http://192.168.31.70:18810`）或用户在 NAS 上直接编辑。

## 安全发布流程（必须遵守）

```
1. 本地修改代码
2. 本地验证（语法检查 + 逻辑检查）
3. 同步到桌面 Workspace
4. 同步到 Git（commit + push）
5. 最后才同步到 NAS（通过 SSH）
6. NAS 上重启容器并验证日志
```

**绝对禁止**：跳过本地测试直接推送到 NAS，或在 NAS 上直接改代码。
